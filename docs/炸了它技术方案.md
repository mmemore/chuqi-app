### 3.2 API 模型 `src/types/api.d.ts`

```typescript
import type { PosterData } from './domain'

/** 通用响应信封 */
export interface ApiEnvelope<T> {
  code: 0 | number                     // 0 = 成功；非 0 见错误码表
  msg: string
  data: T
  ts: number                           // 服务端时间（ms）
}

/** 错误码 */
export enum ApiErrCode {
  SUCCESS = 0,
  PARAM_INVALID = 40001,
  CONTENT_RISKY = 40301,               // 内容安全拦截
  CONTENT_LIMIT = 40302,               // 长度超限
  QCODE_QUOTA = 42901,                 // 小程序码配额
  INTERNAL = 50000,
  NETWORK = -1,
}

/* === getMiniProgramCode === */

export interface GetMiniProgramCodeReq {
  scene: string                        // 最大 32 字符，例：'obj_sandbag_2026-09-07'
  page?: string                        // 默认 'pages/index/index'
  width?: number                       // 默认 430
  /** 缓存策略：'bypass' 强制新生成；'reuse' 24h 内复用 */
  cache?: 'bypass' | 'reuse'
}

export interface GetMiniProgramCodeRes {
  qrcodeUrl: string                    // CDN 临时 URL
  scene: string
  expireAt: number                     // ms
  cached: boolean
}

/* === textSecCheck === */

export interface TextSecCheckReq {
  content: string                      // 最大 2500 字
  openid: string                       // 匿名 UUID
  scene: 'poster_quote' | 'share_msg'  // 调用上下文
}

export interface TextSecCheckRes {
  pass: boolean
  riskLevel: 0 | 1 | 2 | 3             // 0 正常，3 高危
  suggest: 'pass' | 'rewrite' | 'block'
  traceId: string                      // 微信返回的 trace_id，用于申诉
}

/* === reportEvent === */

export interface ReportEventItem {
  name: EventName                       // 见 §4.3
  payload: Record<string, unknown>
  ts: number                            // 客户端 ms
  openid: string                         // 匿名 UUID
}

export interface ReportEventReq {
  events: ReportEventItem[]             // 批量，单次最多 50 条
  appVersion: string
}

export interface ReportEventRes {

  duplicated: number                    // 幂等去重命中
}
```

### 3.3 错误码扩展

| 码 | 含义 | 前端处理 |
|----|------|---------|
| 0 | 成功 | 正常 |
| 40001 | 参数无效 | 弹 Toast「操作失败」并埋点 `api_param_error` |
| 40301 | 内容违规 | 内容场景：替换为安全语录（前端预置 30 条兜底） |
| 40302 | 内容超长 | 截断 + Toast |
| 42901 | 小程序码配额 | 降级：海报显示占位 + 「扫码一起炸」文案（PRD §5.2.2 边界） |
| 50000 | 服务异常 | 重试 1 次（指数退避 1s），仍失败则降级 |
| -1 | 网络异常 | 静默降级，海报无小程序码 |

## 4. API 接口

> 「API」在 V1.0 特指**前端 → 微信云函数**的契约。后端开发者按本节实现云函数即可。

### 4.1 接口总览

| ID | 名称 | 调用方式 | 鉴权 | 频率限制 | 错误降级 |
|----|------|---------|------|---------|---------|
| API-1 | getMiniProgramCode | 同步等待（生成海报阻塞） | wx-context 自动鉴权 | 5/min/openid | 占位图 + 文案 |
| API-2 | textSecCheck | 异步（语录用） | wx-context | 60/min/openid | 走预置安全语录 |
| API-3 | reportEvent | 后台批量 | wx-context | 10/min/openid | 本地缓存，下次启动重试 |
| API-4* | 语音识别 ASR | V1.1 预留 | — | — | — |
| API-5* | 语音变声 | V1.1 预留 | — | — | — |

### 4.2 接口详细规范

#### 4.2.1 API-1 getMiniProgramCode

- **路径**：`cloudfunctions/getMiniProgramCode/index.js`
- **触发时机**：用户完成爆炸、海报组件挂载时调用一次。
- **入参**：`GetMiniProgramCodeReq`
- **出参**：`ApiEnvelope<GetMiniProgramCodeRes>`
- **关键逻辑**：
  1. 调用微信 `openapi.qrcode.getUnlimitedQRCode`，scene 编码为 `obj_{objectType}_{YYYY-MM-DD}_{openidShort}`
  2. 上传返回的 buffer 到云存储，拿到 CDN URL
  3. 缓存键 `scene_qrcodes/{scene}`，TTL 24h，命中直接返回（`cached: true`）
  4. 配额耗尽时抛 `QCODE_QUOTA`，前端降级
- **幂等**：`scene` 相同 + `cache: 'reuse'` 时返回缓存；`bypass` 时强制新生成。
- **安全**：scene 不允许包含明文 `openid`，仅放短哈希，避免被反推。

#### 4.2.2 API-2 textSecCheck

- **路径**：`cloudfunctions/textSecCheck/index.js`
- **触发时机**：分享/海报文案有**用户来源**内容时调用。V1.0 纯预置语录，可暂时只用在「分享消息」（微信 `onShareAppMessage` 的 `title`）。
- **入参**：`TextSecCheckReq`
- **出参**：`ApiEnvelope<TextSecCheckRes>`
- **关键逻辑**：
  1. 调用微信 `openapi.security.msgSecCheck`，version=2（推荐的新版接口）
  2. `result.suggest === 'risky'` 时返回 `pass=false`、`riskLevel=2+`、`suggest='block'`
  3. 单条调用耗时通常 <300ms，不做缓存（合规层面避免过期配置）
- **降级**：调用失败默认按「通过」处理 + 异步埋点 `sec_check_fallback`。

#### 4.2.3 API-3 reportEvent

- **路径**：`cloudfunctions/reportEvent/index.js`
- **触发时机**：前端 `utils/report.ts` 队列每 30s flush 一次；退出小程序时同步 flush；累计 50 条强制 flush。
- **入参**：`ReportEventReq`（`events[] ≤ 50`）
- **出参**：`ApiEnvelope<ReportEventRes>`
- **关键逻辑**：
  1. 写入 `event_logs` 集合（按日期分区），单条幂等键 `openid+name+ts`
  2. 同步聚合到 `daily_stats`：`$inc` 对应计数
  3. 失败的事件写 `event_logs_dead`，下次启动重试
- **存储结构**（云数据库）：

```javascript
// collection: event_logs
{
  _id: string,
  openid: string,
  name: string,
  payload: object,
  ts: number,
  date: 'YYYY-MM-DD',   // 索引
  appVersion: string,
  receivedAt: number    // 服务端 ms
}

// collection: daily_stats
{
  _id: 'YYYY-MM-DD',                     // 主键 = 日期
  punchCount: number,
  explodeCount: number,
  objectSwitchCount: number,
  posterShowCount: number,
  posterSaveCount: number,
  posterShareCount: number,
  // 衍生指标：服务端每日跑一次聚合任务计算（不在 API-3 中实时计算）
  // angerFullCount, shareRate, explodeRate
}

// collection: scene_qrcodes
{
  _id: 'scene',
  qrcodeUrl: string,
  expireAt: number,
  createdAt: number
}
```

### 4.3 埋点事件字典（同步 PRD §10.1，给出 payload 结构）

```typescript
// src/types/event.d.ts
export type EventName =
  | 'app_launch'
  | 'punch_click'
  | 'anger_full'
  | 'anger_explode'
  | 'poster_show'
  | 'poster_save'
  | 'poster_share'
  | 'object_switch'
  | 'settings_change'
  | 'privacy_accept'
  | 'sec_check_fallback'

export interface EventPayloadMap {
  app_launch:        { scene: string; appVersion: string }
  punch_click:       { objectType: PunchObjectType; angerValue: number; combo: number }
  anger_full:        { objectType: PunchObjectType; durationMs: number; punchCount: number }
  anger_explode:     { objectType: PunchObjectType; angerFullTs: number }
  poster_show:       { objectType: PunchObjectType; quoteId: number }
  poster_save:       { objectType: PunchObjectType; success: boolean; reason?: string }
  poster_share:      { objectType: PunchObjectType; channel: 'wx' | 'album' }
  object_switch:     { from: PunchObjectType | null; to: PunchObjectType }
  settings_change:   { key: keyof Settings; from: unknown; to: unknown }
  privacy_accept:    { ts: number }
  sec_check_fallback:{ api: 'textSecCheck'; errorCode: number }
}
```

上报策略：

- **关键事件立即 flush**：`anger_full`、`anger_explode`、`poster_share`（影响北极星指标）
- **普通事件批量 flush**：`punch_click`、`object_switch`（高频，避免抢占通道）
- **次日凌晨清零**：客户端检测 `new Date()` 跨日时 `daily_stats` 重建并埋 `app_launch`

## 6. 性能与安全策略

### 6.1 性能

| 指标 | 目标 | 手段 |
|------|------|------|
| 冷启动 ≤ 2s | ✅ | pages.json 异步分包；首页不引 echarts；首屏关键 CSS 内联 |
| 点击到震动 < 50ms P95 | ✅ | `useVibration` 同步调用 `uni.vibrateShort`，无 await |
| 粒子 60fps | ✅ | `requestAnimationFrame`；低端机 60 个粒子；Canvas 离屏渲染 |
| 主包 ≤ 1.5MB | ✅ | 资源全部 CDN；echarts V1.0 不引；自研粒子 |
| 节流 | ✅ | 单次有效点击 200ms 节流（PRD §5.2.1） |

### 6.2 安全

| 事项 | 方案 |
|------|------|
| 内容审核 | 所有用户来源文本（V1.0 仅分享标题）走 `msgSecCheck` |
| 隐私 | 仅匿名 UUID；不收集地理位置/通讯录；设置页可清缓存 |
| 小程序码 scene | 不放明文 openid，仅哈希前 8 位 |
| 设备指纹 | 不使用，PRD §11 明确禁止 |

## 8. 风险与回退

| 风险 | 触发条件 | 回退方案 |
|------|---------|---------|
| 云函数冷启动慢 | P95 > 1.5s | 海报降级为无小程序码；预热函数 |
| 小程序码配额耗尽 | API-1 返回 42901 | 海报降级为「扫码一起炸」文案（PRD §5.2.2 边界） |
| 主包超 1.5MB | visualizer > 1.5MB | 强制图片 CDN 化；移除 dayjs 用原生 Date |
| 低端机粒子卡 | iPhone 8 fps < 45 | 自动降到 30 粒子，DPR=1 |
| 后端从云开发迁自建 | DAU > 5w 或合规要私有部署 | alova 实例换 baseURL；接口契约不变 |
